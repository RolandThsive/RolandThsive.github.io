# ============================================================
#  TEMPLATE  -  model parameter file
#  https://RolandThsive.github.io/ModelParameters/TEMPLATE.txt
# ============================================================
#
#  HOW IT WORKS
#  For a model at   .../3D_models/Name.glb
#  the page reads   .../ModelParameters/Name.txt
#  So: copy this file, rename it to match the .glb, fill it in.
#  No file for a model = the viewer keeps its HTML defaults.
#
#  FORMAT
#  One "key = value" per line. Keys are model-viewer attribute names.
#  none            -> not set (the post's HTML default is kept)
#  true / false    -> add / remove an on-off flag (autoplay, ar, camera-controls...)
#  Lines starting with # are ignored. The real files don't need any comments.
#
#  This file overrides the viewer's HTML, including loading / reveal.
#  Only src and poster are not here: the slide buttons define those.
#
#  LOADING
#  loading:  lazy (default, waits) | eager (download immediately)
#  reveal:   manual (default, shows the "Load 3D Model" button) | auto | interaction
#
#  EXAMPLES
#  camera-orbit = 169.6deg 101.2deg 0.2632m
#  field-of-view = 30deg
#  min-camera-orbit = auto auto 0.15m
#  tone-mapping = neutral
#  ar-modes = webxr scene-viewer quick-look
# ------------------------------------------------------------
